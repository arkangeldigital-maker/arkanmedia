# ArkanMedia

Nueva versión del sitio de [arkanmedia.com](https://arkanmedia.com/): diseño de páginas web, apps móviles e imagen corporativa en Veracruz.

Sitio estático (HTML, CSS y JavaScript sin dependencias). Para verlo en local:

```bash
python3 -m http.server 8765
```

y abre http://localhost:8765.

- `index.html`: estructura y textos
- `css/style.css`: estilos, colores corporativos (`--red: #d30303`, `--teal: #2caab3`, `--blue: #2c8cb3`) y animaciones
- `js/main.js`: proyectos, clientes, efectos (partículas, aparición al hacer scroll, contadores, inclinación 3D) y formulario de contacto
- `assets/`: logo, logos de clientes y capturas de proyectos tomados del sitio actual
